# [Light Bootstrap Dashboard React](https://demos.creative-tim.com/light-bootstrap-dashboard-react/#/?ref=lbdr-readme)

**[Light Bootstrap Dashboard React](https://demos.creative-tim.com/light-bootstrap-dashboard-react/#/?ref=lbdr-readme)** คือเทมเพลตแดชบอร์ดสำหรับผู้ดูแลระบบที่ออกแบบมาให้สวยงามและเรียบง่าย สร้างขึ้นบน [React Bootstrap](https://5c507d49471426000887a6a7--react-bootstrap.netlify.com/) โดยใช้ [Light Bootstrap Dashboard](https://www.creative-tim.com/product/light-bootstrap?ref=lbdr-readme) และตอบสนองต่อทุกขนาดหน้าจอได้อย่างสมบูรณ์แบบ มาพร้อมกับชุดองค์ประกอบมากมายที่จะช่วยให้คุณสร้างแอปพลิเคชันที่ตรงกับความต้องการของคุณได้หลากหลายรูปแบบ สามารถใช้สร้างแผงควบคุมผู้ดูแลระบบ ระบบจัดการโครงการ เว็บแอปพลิเคชันส่วนหลังบ้าน CMS หรือ CRM ได้

ผลิตภัณฑ์นี้เป็นชุดเครื่องมือสำหรับนักพัฒนาส่วนหน้าขนาดใหญ่ที่จะช่วยให้คุณเริ่มต้นโครงการได้อย่างรวดเร็ว เราสร้างมันขึ้นมาโดยคำนึงถึงสิ่งที่คุณต้องการจริงๆ ในแดชบอร์ด Light Bootstrap Dashboard React ประกอบด้วยปลั๊กอินที่คัดสรรและปรับแต่งมาอย่างดีมากมาย ทุกอย่างถูกออกแบบมาให้ทำงานร่วมกันได้อย่างลงตัว ดังที่คุณจะเห็นได้ แดชบอร์ดที่คุณสามารถเข้าถึงได้บน Creative Tim คือการปรับแต่งจากผลิตภัณฑ์นี้

มาพร้อมกับสีตัวกรอง 6 สีสำหรับแถบด้านข้าง (ดำ ฟ้า เขียว ส้ม แดง ม่วง) และตัวเลือกในการใส่ภาพพื้นหลัง

## Reporting Issues

We use GitHub Issues as the official bug tracker for the Light Bootstrap Dashboard React. Here are some advices for our users that want to report an issue:

1. Make sure that you are using the latest version of the Light Bootstrap Dashboard React. Check the CHANGELOG from your dashboard on our [website](https://www.creative-tim.com/?ref=lbdr-readme).
2. Providing us reproducible steps for the issue will shorten the time it takes for it to be fixed.
3. Some issues may be browser specific, so specifying in what browser you encountered the issue might help.
